# Glossary

These terms are used precisely and consistently in the code, the API and these
pages. Where a word has a broader meaning in the industry, the narrow one below
is what MAYA means by it.

## The pairs worth getting right

Almost every question this page is opened for is really a question about a
distinction. Here are the ones that cause the most trouble.

| | | |
|---|---|---|
| **Version** vs **parameter set** | the *kernel* | a *point of `P`*. Refitting produces a new point, not a new kernel — which is what lets a daily recalibration be approved once |
| **Featureset** vs **featureset version** | a *schema* of named slots | a *binding* of every slot to a feature and an exact pinned view version |
| **Approval** vs **attestation** | one person in the second line saying the work is sound | the quorum that puts the record **in force**; every required role signs and one decline ends it |
| **Grant** vs **warrant** | the standing *entitlement* | the signed, expiring *document* minted against it at the moment of use |
| **Debt** vs **breach** | we know this is missing, and when it will be fixed | a control that should have operated did not. Debt blocks nothing and raises no finding — until its expiry, when it becomes the other |
| **Finding** vs **blocking finding** | something challenge found | the same thing with one column set, which refuses alias promotion, warrant resolution and an `approved` validation |
| **Compiled** vs **attached** document | generated by lenses reading the register; cannot drift | written by a person; supersession is how it is replaced |
| **`lineage()`** vs **`rests_on()`** | every ancestor, derived features included — *what would break if this changed* | the base features only — *what data does this ultimately read* |
| **Alias** vs **URN** | a named, environment-scoped pointer at a version | the permanent handle. Consumers bind to the URN and an alias, never to a version |

## A to C

**Alias** — a named, environment-scoped pointer at a version, such as
`champion` in `prod`. Consumers bind to aliases, never to versions, which is why
a version can be replaced without anyone redeploying. An alias move is a proof
obligation: refinement (L-7) and variance (L-12) are checked, and an open
blocking finding refuses it.

**Amendment** — a declared change to an attested record. It names what is
changing and why, returns the record to `amending`, and must itself be
submitted, approved and attested. The only route out of immutability.

**`AsOf`** — the point-in-time read, written as an operator rather than a
condition: `AsOf(R, ℓ, a)` takes the latest row whose event time is at or before
the label `ℓ` and whose ingest time is at or before `min(ℓ, a)`. That `min` is
the reproducibility guarantee (**L-10**): every read at or after the label gives
the same answer, however many restatements arrived in between.

**Artifact digest** — the content hash of whatever actually runs. MAYA may hold
the bytes under that address or only the digest and a reference; the warrant
carries which, as `held_by_maya`.

**Assumption** — a bound on an input under which the model's guarantees hold.
Outside it, the guarantee is void.

**Attestation** — the quorum that puts a record in force: every required role
signs, and one decline ends it. Distinct from approval, which is one person in
the second line saying the work is sound.

**Baselined** — a model imported from an existing estate: in the inventory,
tiered, governed going forward, and explicitly **not** asserting historical
evidence. A mutable state, so the next material change goes through the full
path.

**Bitemporal** — carrying two clocks: valid time (when a fact was true) and
transaction time (when we learned it). See
[the two clocks](/help/features-and-two-clocks).

**Blast radius** — what breaks downstream if this model changes, followed along
`input_to` edges only. It is trustworthy because those edges type-check.

**Blocking finding** — an open finding that refuses alias promotion, warrant
resolution and an `approved` validation outcome. Critical severity blocks by
default; any finding can be made blocking explicitly.

**Board pack** — the estate reported against the limits somebody set, with the
exceptions, what moved since the last pack, and what could not be measured. Kept
as it was read, so a minute referring to "the March pack" refers to something.

**Compliance debt** — a recorded, dated gap in a baselined model's evidence.
Computed from the register rather than declared, so nobody can under-declare.
Closes by itself when the evidence arrives; at its expiry it raises a finding at
the gap's own materiality.

**Contract** — an assume-guarantee pair. Contracts *refine* one another: a
replacement must assume no more and guarantee no less (**L-7**).

## D to G

**Declared use** — what a principal says it will do with a model. Resolution
refuses if it is not the approved use.

**Derived feature** — a feature computed from other features by a small, total
expression language. It is a *term*: its provenance polynomial's free variables
are its base features, its ingest clock is the maximum of its inputs', and it
may not read the label.

**Descriptor-only** — a version MAYA holds the governance for without holding
the artifact: no digest recorded, or no runtime declared. It is read off the
record rather than set as a flag, and law **L-W6** refuses to fit one.

**Document subject** — what a document is *about*: `model`, `model_version`,
`parameter_set`, `featureset_version`, `feature` or `validation`. Three of those
are pinned by construction, and `featureset` is deliberately absent from the
vocabulary.

**Dossier** — the whole documentation graph walked from one model, following the
pins, with every node that has nothing filed named as a gap. Computed, never
stored.

**Evidence node** — one entry in the append-only hash chain. Carries a sequence
number, a kind, a subject, a payload, who recorded it, and hashes linking it to
its predecessor. Authorship is *inside* the content hash, because segregation of
duties is read from it.

**Export pack** — everything about one model as a digested, self-contained zip,
for somebody who will never be given a login. Its `gaps.md` is read first.

**Featureset** — a named, declared **schema** of typed slots that a kernel can
be defined over, and that a warrant can ask for by name.

**Featureset version** — a binding of each slot to a feature and the exact
feature view version supplying its values. A version that cannot fill the schema
is refused.

**Feature contract** — a binding of a model version to exact feature view
versions. What serving *must* read (**L-17**).

**Feature view** — a named, owned collection of features over one entity,
materialised into versioned Delta namespaces.

**Grace** — extra time a warrant's authorisation stays current when the control
plane is unreachable. It never extends revocation ignorance.

**Guarantee** — a property the model promises when its assumptions hold.

## H to P

**`input_to`** — the dependency relation: what the source model produces is read
as an input by the target. It is a **typed composition**, refused unless the
ends compose (**L-21**), not a drawing. `feeds` is accepted on the way in and
stored under this name; it is not published as a second word for one relation.

**Kernel** — the shape every model in MAYA takes: `f : P ⊗ X → D(Y)` — a
parameter object, an input, and a *distribution* over outputs. Training does not
change `f`; it inhabits `P`.

**Lattice** — the order on schemas. `A ⊑ B` means *A can stand in for B*: A has
every field B has, each accepting at least what B's accepted. The **meet** is
what a featureset must provide to serve two models at once; the **join** is what
two schemas agree on. One order answering four questions that used to have four
implementations (**L-20**).

**Lens** — a section of a compiled document that goes and reads the register,
rather than a template that interpolates what it was handed. A lens that cannot
fill its section returns nothing, which is how a gap is named.

**Manifest digest** — the content hash of a version's full specification.
Stable, so the same version registered twice from two pipelines is detected.

**Materiality** — how much is at stake: exposure joined with purpose. One of the
two lattices feeding the tier.

**Namespace** — the Delta path a specific feature view version serves from. A
version *is* a namespace.

**Operating boundary** — the assumptions in force, checked by the execution
engine before invoking the artifact.

**Oracle** — a predicate that decides mechanically whether a generated artifact
is correct, without asking the thing that generated it. A Tier A machine
assistance capability must name one.

**Overlay** — a human adjustment applied on top of a model's output. Time-boxed,
measured, approved by somebody who did not propose it, renewed by somebody who
does not own it, and a finding if it keeps being renewed.

**Parameter object (`P`)** — the parameters of a model, in the sense
`f : P ⊗ X → D(Y)`. How `P` is inhabited gives the trainability class.

**Parameter set** — a stored, immutable, versioned inhabitant of `P`, with the
featureset version, window and warrant that produced it. Fitted sets are
accepted only against a warrant MAYA issued, and approved by somebody other than
whoever recorded them.

**Point-in-time (PIT)** — the property that an assembled row uses only facts
that were true by the label time and known by the as-of time.

**Policy gate** — a versioned rule that can add a condition to a decision, never
remove one. Authoring and publishing are separate duties, and publishing reports
every verdict that flipped.

**Principal** — the identity a warrant is issued to. A service, not usually a
person.

**Provenance polynomial** — the value of a claim in `ℕ[X]`, the free commutative
semiring on the base facts. Every other provenance answer is a **pushforward**
of it, which is what makes one traversal answer six questions a theorem rather
than a coincidence (**L-9**).

## Q to Z

**Quorum** — the requirement that two people in two named roles sign. It applies
to attestation, and to version approval at Tier 1 and Tier 2. The same person
may not sign twice under two hats.

**Refinement** — the ordering on contracts. New refines old when it assumes no
more and guarantees no less. Checked on every alias move (**L-7**).

**Regime** — a supervisory framework encoded as its own signature, its own
obligations and a translation into MAYA's vocabulary. It cannot be activated
unless truth survives that translation (**L-8**), nor if it obliges and forbids
the same term (**L-16**).

**Revocation epoch** — a counter bumped by revocation. Warrants carry the epoch
they were minted under, so an engine can tell a stale credential from a current
one.

**Revocation floor** — the rule that a revoked warrant is refused regardless of
grace state.

**Risk appetite** — a declared threshold over a metric the platform derives, so
utilisation is arithmetic and a breach is a fact. Versioned, never edited, and a
change that made the limit easier to satisfy is recorded as a relaxation.

**Scope** — the models a permission may be exercised over, by legal entity and
domain. An empty list is unrestricted; scope filters listings before the page is
cut, not just detail pages.

**Segregation of duties** — the rule that what you may do next depends on what
you already did, computed from the evidence chain rather than from a separate
table.

**Semiring** — the algebraic structure that parameterises one provenance
traversal into several questions: Boolean, counting, why-provenance, trust and
cost. **Freshness is not one** — it is `(max, max)`, its zero does not
annihilate, and the universal property does not reach it, so a claim resting on
a missing fact reports the freshness of the facts that *are* present.

**Shared dependency** — what two or more models both rest on. The reason
aggregate model risk cannot simply be added up, made computable.

**Snapshot** — a named, digested, immutable dataset produced by an assembly,
with its PIT report attached and a pinned Delta version, which is what a
validation replay reads at.

**Telemetry** — scored rows and outcomes delivered to MAYA per model version, on
two clocks, joined when they are read rather than when they arrive. Ingestion is
idempotent on the batch's own digest.

**Tier** — 1 (highest scrutiny) to 4, computed from materiality and complexity
by a monotone function (**L-4**); the controls each tier requires stand in a
Galois adjunction with it (**L-5**).

**Trainability class** — T0–T8, derived from how the parameter object is
inhabited and by what procedure — never declared. `none` gives **T0**,
`calibrate` **T1**, `estimate` **T2**, `train` **T3** (or **T4** where the model
is adaptive), `configure` **T5**, an opaque vendor parameter object **T6**,
`elicit` **T7**, `author` **T8**. See
[Registering a model](/help/registering-a-model#trainability-classes-t0-to-t8).

**Training record** — the compiled document about one parameter set: the warrant
that authorised the fit, the featureset version it read, the window, the `as_of`
and the diagnostics. Compiled rather than written, so a model recalibrated every
morning has one for every morning.

**URN** — the permanent model handle, `maya://model/<name>`. No version and no
environment in it.

**Variance** — the schema compatibility rule: inputs contravariant, outputs
covariant (**L-12**).

**Warrant** — a signed, expiring, entitlement-bound document authorising a named
principal to perform a stated operation on a stated model version. Distinct from
a **grant**, which is the standing entitlement a warrant is minted against.

**Warrant profile** — request defaults selected by facts the platform derives.
A profile fills holes in a request; it never overrides a caller, and a profile
reaching for authority is refused at creation.

**Worklist** — what needs doing, derived from the register rather than assigned,
and filtered to what you personally hold the permission and the scope to do.
