## Marks

`assets/logo/` holds the full set. Pick by background, not by size.

| File | Use |
|---|---|
| `maya-mark.svg` | The mark. Default, on light backgrounds. |
| `maya-mark-white.svg` | The mark, on dark backgrounds. |
| `maya-mark-mono.svg` | Single colour, for stamping, faxing, embroidery. |
| `maya-lockup.svg` | Mark plus wordmark, side by side. |
| `maya-mark-{64,128,256}.png` | Raster fallbacks, for favicons and anywhere SVG is not accepted. |
| `maya-mark-transparent.png` | Raster, on an unknown background. |
| `_concepts-considered.png` | The rejected concepts. Kept as a record of why this one won; not for use. |

Prefer the SVG. The PNGs exist for the places that refuse one.
