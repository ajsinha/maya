## I. Platform, interfaces and operations — sequences and judgement

`docs/QA/QA-CASES.md` holds 1,636 cases generated from the source: every
operation once, every required-field refusal, every unknown-identifier 404,
every mapped refusal code, and every navbar screen against a role that should
see it and one that should not. Those guarantee nothing is **missing**.

This file is the half a generator cannot produce. Every case here is a
**sequence**, a **boundary**, a **race**, or a **combination** — a control that
is right on its own and wrong beside another one. Nothing here repeats a
generated case: where a case names an operation the generator already covers, it
is the *second* call, the *stale* header, the *concurrent* writer or the
*restored* instance that is being tested, never the happy path.

**Every expectation is stated before the case runs**, as `accepted`,
`refused (code)` or `reported`. `refused (code TBD)` means the refusal is
required and the code has not been read out of the source yet — that is a case
outcome to record, not a case to skip.

**Three house rules apply to every case below.**

1. **A refusal is usually the feature working.** A 409, a 412 or a 423 that
   carries `error`, `detail` and `remediation` is a pass when the case predicted
   it. What is reportable is the opposite: a success that corresponds to nothing.
2. **A screen case must prove it got the page it asked for.** The interface
   ignores HTTP Basic and answers **200 with the sign-in page**, which has
   already fooled one test pass. Asserting `200` proves nothing. Assert on
   `href="/logout"` in the body — present only when a session is established —
   and on the page's own `<title>`. `403` renders `forbidden.html`, whose title
   is `Not available to you`, the only page title in the product that omits
   ` — MAYA`.
3. **Mark the environment.** Cases tagged **[PG]** need
   `database.url: postgresql+psycopg://…`; **[ICEBERG]** need
   `data.table_format: iceberg` (or `MAYA_TABLE_FORMAT=iceberg`, which wins over
   the file). A previous pass could run neither and said so. Untagged cases run
   on the SQLite/Delta default.

Estate under test is the one `docs/QA/qa_setup.py` builds — model
`maya://model/qa.pd.scorecard` at `1.0.0`, principals `admin`, `q.tester`,
`s.iqbal`, `j.okafor`, `a.mehta`, `d.raman`, `svc/qa-runner`. Run the instance
on a non-default port with a config in a temporary directory, never against the
repository's own `data/`.
