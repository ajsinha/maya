## F. Governance — sequences and judgement

Hand-written cases for registration, the record lifecycle, versions and
promotion, the approval quorum, risk tiering, segregation of duties, and
decommissioning. These are the half a generator cannot produce: orderings,
boundary values, races, re-runs, and the specific ways two controls that are
each correct combine into a hole. Every operation already has a happy-path case
in section A and every mapped refusal code a provocation case in section D, so
nothing here repeats those.

Read `refused (code)` as: the platform says no and the response body's `error`
field is that code. Where the code is written `code TBD` the case names what to
look for instead.
