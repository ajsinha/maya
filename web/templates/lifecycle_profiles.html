What each move costs

Every model in this register is on the same state machine. That is deliberate and it is not a simplification: every law the platform rests on is a statement about that graph — L-1 is a reachability proof over exactly two initial states, and the immutability of an attested record is the reason amendments exist. Nine graphs would mean nine reachability proofs, nine answers to can this be changed, and a supervisor who has to ask which machine a model is on before reading its status.

What varies is what each move costs. The trainability class says which evidence must be on file before a record can be attested — L-15 already makes each class declare that, and this screen is the first thing in the platform that reads the declaration. The tier says how many signatures the move takes and how long it may sit.

Records nobody is waiting on
A record that has been submitted for four months is not blocked by any control here — the submission succeeded and every gate passed. That is how a governance queue becomes a place things go to wait, and the only reason it is invisible is that no state carries an expected duration. None of this is refused: a queue is allowed to have a queue, but one with no expected duration is one nobody can tell is stuck.

What each class owes before it can be attested
Only attestation is guarded by evidence, and that is the point: it is the moment a record becomes immutable and in force. Checking earlier would block a draft for lacking a validation report nobody could have written yet, and a control that fires before it can be satisfied teaches everybody to route around it.
