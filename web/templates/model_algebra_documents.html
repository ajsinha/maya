A document attaches to a version, not merely to a model: “the model development document” is about a particular version, and one filed at model level floats free of what it describes. Model level is allowed for the few things genuinely about the model and has to be asked for. Documents are content-addressed, so a file cannot be edited in place — editing produces a different digest, which is a different document, which is a supersession somebody has to declare.
