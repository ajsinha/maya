Define a feature

A feature is a meaning, not a column: an entity, a type, an owner and a definition. It is declared before it has values, because the declaration is what a featureset pins and what an owner is accountable for — a view that materialised an undeclared column would be a feature nobody owns.

2 — A derived feature: Z = f(X, Y)

A value computed from other values. The lineage is recorded, so a primitive cannot be withdrawn while something derives from it; the ingest clock is inherited as a maximum, because you did not know Z before you knew its inputs.

Only for external, and only when MAYA cannot parse the expression. Declared so lineage and the leakage check still have something to work with.

A correction is a new definition version, never an edit: somebody may already have trained against the old one. A definition that would close a loop is refused, and the refusal names the feature the loop closes through.
3 — A feature composed from others

A combination of features is a feature. Inheriting from one parent and combining several differ only in how many parents there are, so there is one mechanism and inheritance is the one-parent case.

Left to right; the rightmost wins.
