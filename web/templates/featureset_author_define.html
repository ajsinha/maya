A featureset declares a schema — named slots with types — and a version fills it. Nothing here is written until you press Declare; everything above that button is POST /featuresets/preview, which resolves what you have typed and declares nothing. The button follows that call and nothing decided in this browser.

1 · What it is called

Owned by {{ user }} — the register takes the owner from whoever is acting and there is no field for it, because an owner somebody typed is an owner nobody is.

2 · Slots it declares itself

The slots are the schema, and the schema is what a kernel is defined over. Adding one later changes X, which is a model change rather than a data change — so it becomes a different featureset and the register says so instead of letting it happen quietly. A slot's type must equal its feature's exactly, so the list offered is the types the catalogue actually carries.

3 · Featuresets it composes from

A combination of featuresets is a featureset. {{ composition.rule }}. The definition of each parent is recorded as you compose, so a parent that moves afterwards is reported as drift rather than changing this one silently. No more than {{ composition.max_depth }} levels.

5 · The label, and how long the outcome takes

Naming a label slot turns the leakage check on: from then on no other slot may hold a feature computed from that one, however many hops away. The window is how long the outcome takes to be known, and it is the reason a model cannot be judged the week it ships.

6 · Default retrieval policy

Attached as this featureset's default behaviour; a request may still override it column by column, and a child inherits it and may override part — the same fold, with the rightmost winning ({{ retrieval.precedence }}). It says {{ retrieval.sections|join(', ') }} and nothing else: a policy that could say anything would be a scripting language wearing a dictionary's clothes.

Declare it

Enabled by the preview returning 200, and by nothing computed here. The preview answers the composition half: the slots, the parents, the operations and the policy. It never sees the name, the label slot or the outcome window, so three refusals can only reach you when you press this — a name already taken, a label slot that is not one of the slots this resolves to, and a negative window. They are refusals, not damage: nothing is written when one happens.
