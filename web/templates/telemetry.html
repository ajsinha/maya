No versions are registered, so there is nothing that could be sending. Telemetry is per model version rather than per model: two versions of one model score different populations, and a monitor that mixed them would be judging neither.
A version that has stopped sending is what this page exists to surface. A monitor evaluated over a stale window still returns a number, and the number describes a population that is no longer being produced — so the silence is the finding, not the absence of one.
