The schema lattice

{% include "featureset_author_nav.html" %}

A ⊑ B reads “A can stand in for B”: A has every field B has, each accepting at least what B's did. A may have extra fields — they are simply not read — and a shared field that accepts less is a regression, because a replacement that rejects an input its predecessor took breaks a caller. Four questions in this platform are that one relation: can this version replace that one (L-12), can this featureset be fitted from by that kernel (L-W10), can one featureset serve two models, and what do two schemas agree on. They are answered by core.domain.lattice, written once, and this page asks it.

Pick two

A featureset contributes FeaturesetRegistry.schema — the same object L-W10 compares, with the label left out, because a kernel does not read the answer. A model version contributes the input schema it declares. ⊤ is the empty schema, which demands nothing. A GET because nothing here is written or recorded.
