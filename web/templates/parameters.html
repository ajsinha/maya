A model is f : P × X → D(Y). Fitting does not change f — it picks a point in P. So a fit produces a parameter set rather than a model version: the kernel did not change, and minting a version for every retrain would make “the model changed” mean two different things. A parameter set does change behaviour, so it is approved the way a version is.
