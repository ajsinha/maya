THE TWO CLOCKS

Ask a point-in-time question

Most “model failures” are feature failures. A model that scored 0.47 in development and 0.31 in production has usually not degraded; it was never trained on the data it is now served, because a future value leaked into a past row. The rule that prevents it is one sentence: a training row may read only what was true by the moment of the decision and known by then as well.

The operator
AsOf(R, ℓ, a) = argmax over ({{ clocks.valid_time }}, {{ clocks.ingest_time }}) of
                { r ∈ R : r.{{ clocks.valid_time }} ≤ ℓ  ∧  r.{{ clocks.ingest_time }} ≤ min(ℓ, a) }

ℓ is the moment of the decision — the label time. a is the moment the set was assembled. The two bounds refuse different things: ℓ is what could have been known when the decision was made, a is what the platform could have known when the set was built. The ingest clock is bounded by the smaller of them, and that min is the reproducibility law — every a ≥ ℓ gives the same answer, so a row assembled the day its label matured and the same row re-assembled a year later are identical, however many restatements arrived in between.

PropertyWhat it means here
idempotentreading the result again returns it
commutes with projection reading fewer columns cannot change which row is admissible; the choice is made on the clocks alone
monotone in a a later assembly can only widen what is admissible; nothing that was knowable stops being knowable
saturating at ℓ every a ≥ ℓ gives the same answer — the reproducibility guarantee

Each is asserted in tests/test_laws.py rather than argued here, and the verdicts below come from the same function TrainingSetBuilder.latest_admissible an assembly uses — this page holds no second copy of the rule.

Ask it of loaded rows

Reads a stored view version and says, row by row, which is admissible and which clock refused the rest. Writes nothing: no snapshot, no evidence, no warrant. Asking which row the rule admits is not the same act as building a training set out of the answer.

Assemble a training set — the act, not the question

This one writes: it joins a spine to the pinned view versions under the rule above, verifies the result by independently recomputing a sample, and records a snapshot with the verification report attached. Turn either bound off and the assembly is refused before a single row is read — that refusal is a proof, not a warning.
