Featuresets

A featureset declares a schema — named slots with types — and a version fills it, binding each slot to a feature and to the exact feature view version supplying its values. Two versions may hold entirely different features and still be the same input space, because the kernel reads the slot.

Declare a featureset
Attached to the featureset as its default behaviour; a request may still override it, column by column. A child inherits it and may override part — the same left-to-right fold, with the rightmost winning.
The slots are the schema. Adding one later changes X, which is a model change rather than a data change — so it is a different featureset, and the register says so rather than letting it happen quietly.
