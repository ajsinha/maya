Create a view, and load values into it

A feature view is the namespace values live in, and a version is a namespace. Loading again does not overwrite what an earlier version serves — they are different Delta paths — so a model pinned to v7 keeps reading v7 after v8 is written. Every row carries {{ clocks.entity }} and both clocks: {{ clocks.valid_time }} when the fact was true and {{ clocks.ingest_time }} when the platform learned it.
