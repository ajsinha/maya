API keys

How a service authenticates without a password. A password names a person and carries everything they hold, for as long as the account exists. A key names a credential: it expires, it can be narrowed to a subset of what its principal holds, and it can be revoked without touching the account — which is what makes rotating one an ordinary Tuesday rather than an outage.
