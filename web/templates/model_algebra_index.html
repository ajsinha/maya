A model is a parametric kernel, f : P ⊗ X → D(Y). Everything on this page is read from the code that enforces it — the relations from the composition service, the classes from the fibration, the states from the state machine, the quorum from the approval service. Nothing here is a description of the platform kept beside the platform.

The trainability classes, and what each fibre requires

The class is derived from how P is inhabited — never declared, never typed. That is what makes “some models are never trained” a type-level fact rather than a special case, and it is why the fibration is indexed by this and not by the free-text model class. L-15: no fibre is empty.
