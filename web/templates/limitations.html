What the estate says its models cannot do

A limitation is a statement that a model is not valid somewhere. It is worth something only if it is enforced — bound to a clause of the operating contract, so a call outside it is refused — or, failing that, if somebody can find it. This register had no estate-wide view and no screen at all: reading it needed a model urn and a version, so the question it exists to answer could not be asked. A limitation nobody can enumerate is a limitation nobody is managing.
