LLM applications

An LLM application is governed like a model. A version seals the provider, model, system prompt, prompt template, parameters and guardrails in one definition hash. It is judged on evaluation sets with deterministic checks, and approved only on a clean run of that exact definition, by someone who neither owns it nor submitted it.
