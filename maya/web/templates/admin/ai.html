AI models

MAYA drafts documents with a language model through model profiles: logical models that name a provider, a model and how to ask it. Callers name a profile, never a provider, so switching the default here changes what every new document is drafted with, at once.

{% call needs('model-profiles-and-providers', 'How profiles and providers fit together') %}
  • Profiles come from the llm.* settings (settings), config/llm_profiles.yaml (file) and this page (database); one saved here replaces a file profile of the same name.
  • Make default takes effect immediately for every process, is audited, and overrides the file's default: line until you hand the choice back.
  • API keys are never entered here: a profile's options name the environment variable that holds one (api_key_env).
  • A provider is a built-in or a plugin allowed by plugins.allow; Test asks the model one short question before a document relies on it.
