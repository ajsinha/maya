Webhooks

Every committed state change of consequence is an event, written in the same transaction as its audit entry. Webhooks receive them as signed POSTs: verify X-Maya-Signature = sha256=HMAC(secret, timestamp + "." + body), and treat X-Maya-Delivery as an idempotency key — delivery is at-least-once. Failures retry with backoff, then dead-letter.
