Design your compute kernel

Write the mathematics the way you write it — LaTeX, or something close to Python — and MAYA translates it into the typed formula IR a model version holds, renders it back so you can check it read you correctly, and generates one self-contained Python function that computes it. Nothing here is saved: this is the translation step on its own.

One assignment per line. The last line names the output. Available functions: exp log sqrt abs ncdf npdf max min where and the comparisons.

Anything you do not name here is a feature. Declare every multi-letter symbol: an undeclared tau reads the way LaTeX means it, as t·a·u.
