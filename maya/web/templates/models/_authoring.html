  • Formula text: assignments, one per line, ending with the output, e.g. price = S*ncdf(d1) - K*exp(-r*T)*ncdf(d2). Python-like or LaTeX-lite.
  • Roles: every name is a feature (from data) unless you list it, one per line: sigma: parameter (fitted) or r: constant (fixed).
  • Python function: one function, assignments then a single return; no loops, if or other calls. Use where(cond, a, b) for a choice. It may call exp, log, sqrt, abs, max, min, where and the normal cdf/ppf/pdf. Features are plain names or X["name"]; parameters are params["name"]. MAYA reads it as mathematics and does not run it.
def pd_logit(income, utilisation, params):
    z = params["b0"] + params["b1"] * log(income) + params["b2"] * utilisation
    return 1 / (1 + exp(-z))
