What is MAYA?

MAYA is the system of record for quantitative features, feature sets, models, and the warrants that license a model to be trained or run.

Definition, data, documentation, approval and evidence live in one place, so any number a model produced can be rebuilt exactly, years later, by someone who was not there. A version freezes how a number is produced; a pin freezes what it was. A warrant binds this model version, this data and these parameters into one auditable, transferable instrument — and, because it is live, it can be withdrawn on a Friday afternoon when the model is found to be wrong.

Built for model-risk, quantitative research and data teams in regulated firms, where "we think this is what we ran" is not an answer an examiner accepts.

Honest limits

Stated so nobody has to discover them.

  • Not yet built: the assistant as recorded challenger, server-side table paging, SDK record/replay, performance benchmarks.
  • Spreadsheet import lifts a deliberately narrow slice of Excel and refuses the rest by cell.
  • SAML is refused at startup; OIDC SSO and TOTP are shipped. WebAuthn is not built.
  • The strong sandbox tier is Linux-only; macOS runs at moderate, Windows at minimal.
  • Search is MAYA's own inverted index; PostgreSQL tsvector and SQLite FTS5 are not used.
  • Custody anchors are only as external as the storage you point them at.
