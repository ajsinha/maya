{% from "help/_macros.html" import step, concept, tip, warn, example, fields, screen, cards %} {% call concept('The SDK is the only client') %}

The web UI does not talk to MAYA's database or services directly: every screen calls the public Python SDK with your own session, and the SDK calls the REST API at /api/v1. So anything you can do in the browser, a script, a notebook or a CI job can do too, with the same permissions and the same audit trail. The command line is an SDK client as well. The interactive API reference lives at /api/v1/docs.

{% endcall %} {{ cards([ ('code-square', 'Python SDK', 'maya.sdk — Client, AsyncClient and connect(), with one attribute per area.'), ('globe', 'REST API', 'JSON under /api/v1; errors as RFC 9457 problem documents.'), ('terminal', 'Command line', 'python -m maya.cli — features, pins, warrants, jobs, bundles, estate.'), ]) }} {% call step(1, 'Get an API key') %}

Create one under {{ screen('/account/keys', 'your menu → My API keys') }}. The key is shown once; MAYA stores only a hash of its secret. A key can be narrowed to fewer roles than you hold, to particular namespaces, actions and client networks, and expires (90 days by default, never more than auth.api_keys.max_days).

{% call example('Create a narrow key from Python', 'python') %} key = my.auth.create_api_key("nightly-pins", namespaces=["eq"], actions=["read", "pin"], days=30) print(key["api_key"]) # maya_prod__ — copy it now {% endcall %} {% call warn('A key is a bearer credential') %}

The SDK refuses to send a key over plain http:// to anything but localhost. Keep keys in an environment variable or a secret store, never in code or notebooks.

{% endcall %} {% endcall %} {% call step(2, 'Connect') %} {% call example('The shortest path', 'python') %} import maya.sdk as maya my = maya.connect(base_url="https://maya.example.com", api_key="maya_prod_…") for f in my.features.list(namespace="eq"): print(f["name"], f["latest_state"]) {% endcall %}

connect() also reads the environment and a profile file, so scripts carry no credentials:

{{ fields([ ('MAYA_URL', 'the base URL (default http://127.0.0.1:8600)'), ('MAYA_API_KEY', 'the key to use'), ('MAYA_CONFIG', 'profile file path (default ~/.maya/config.toml)'), ('MAYA_DEBUG_AUTH', 'set to print where the credential came from'), ]) }}

~/.maya/config.toml: see Connecting in the full reference below.

{% call example('Use the profile', 'python') %} my = maya.connect("prod") {% endcall %} {% endcall %} {% call step(3, 'A worked example: pin, download, verify') %} {% call example('Month-end pin of a feature set, then training data', 'python') %} import maya.sdk as maya my = maya.connect("prod") job = my.featuresets.pin("eq/panel", version_no=2, pin_name="eom", as_of="2026-03-31", cascade=True, idempotency_key="panel-eom-2026-03-31") my.wait(job, progress=lambda j: print(j["progress"], j["message"])) # training data for a warrant: downloaded, checksum-verified, as an Arrow table table, manifest = my.training_data("") print(table.num_rows, manifest["checksum"]) {% endcall %} {% call tip('Retries are safe where they can be') %}

GET, PUT and DELETE, and any call carrying an Idempotency-Key, are retried on network failures and on 429, 502, 503 and 504. Other writes are not retried, so a pin started twice is started twice unless you give it a key. my.wait() polls a job to a terminal state and never blocks forever.

{% endcall %} {% call tip('Polling is cheap, and a big download is resumable') %}

Listings and definition reads carry an ETag. The client sends it back on the next identical read and MAYA answers 304, so a script that polls a catalog every minute pays for the round trip and not the payload — and nothing is ever served that the server has not just re-affirmed. Editing a draft sends the ETag of the read your edit was written against, so an edit over someone else's raises ConflictError instead of winning silently.

Ask for a download to a file and the bytes stream to disk: if the connection drops, the next call continues from the part already there rather than starting again, and the finished file faces the same checksum either way.

{% call example('A download that survives the VPN', 'python') %} out = my.features.download("eq/prices#eom/2026-03-31", to="/data/prices.parquet") print(out["bytes"], "bytes,", "resumed from", out["resumed_from"]) {% endcall %} {% endcall %} {% endcall %} {% call step(4, 'Handle errors by name') %}

Every refusal arrives as a problem document and is raised as a typed exception, all subclasses of maya.sdk.MayaError:

{{ fields([ ('PermissionDenied', '403 — your roles or grants do not allow it'), ('NotFound', '404 — no such object'), ('ValidationFailed', '422 — the request or definition is invalid; details in the context'), ('ConflictError / NotApproved', '409 — the object moved on, or is not in a state that allows it'), ('ContractMismatch', '422 — inputs do not satisfy a declared input contract'), ('WarrantExpired / WarrantSuspended', '410 / 423 — the execution warrant no longer licenses this'), ('LicenceBreach', '451 — a data licence forbids it, naming the clause and source'), ]) }}

Catch a licence refusal: see Conventions in the full reference below.

{% endcall %} {% call step(5, 'The same over REST') %} {% call example('Sign in, then call the API', 'bash') %} TOKEN=$(curl -s -X POST https://maya.example.com/api/v1/auth/login \ -H "Content-Type: application/json" \ -d '{"username": "val.jones", "password": "…"}' | jq -r .token) curl https://maya.example.com/api/v1/features?namespace=eq \ -H "Authorization: Bearer $TOKEN" {% endcall %} {% call example('A problem document', 'json') %} {"type": "permission_denied", "title": "PermissionDenied", "status": 403, "detail": "…", "context": {}} {% endcall %}

Send a W3C traceparent header and the same trace id follows your call through the API, its audit entries and any job it starts. See Metrics and tracing.

{% endcall %} {% call step(6, 'The command line') %} {% call example('Common commands', 'bash') %} python -m maya.cli --profile prod feature list --namespace eq python -m maya.cli --profile prod feature pin eq/prices --version 1 --name eom --as-of 2026-03-31 python -m maya.cli --profile prod featureset download eq/panel --out panel.parquet --shape tabular python -m maya.cli --profile prod job watch python -m maya.cli --json --profile prod export verify bundle.zip {% endcall %}

--json gives machine-readable output; --local runs against an in-process platform instead of a server (it needs MAYA_USER and MAYA_PASSWORD).

{% endcall %} {% call step(7, 'Record once, replay in tests') %}

Your own code that uses MAYA can be tested without a server. Record a session against a real MAYA once; replay the cassette forever after, in milliseconds, on a machine that has never seen MAYA.

{% call example('Record, then replay', 'python') %} import maya.sdk as maya live = maya.Client.record("tests/fixtures/prices.json", base_url="https://maya.example.com", api_key="maya_…") panel = live.features.preview("maya://feature/eq/prices@v1") # a real call, recorded tape = maya.Client.replay("tests/fixtures/prices.json") # no network at all assert tape.features.preview("maya://feature/eq/prices@v1") == panel {% endcall %} {{ fields([ ('matching', 'method, path, query and a hash of the body and files; identical calls replay in recorded order'), ('refusals', 'replay as the same typed error with the same context: PermissionDenied stays PermissionDenied'), ('credentials', 'never recorded: headers are not kept, and token, secret and password fields are redacted'), ('a miss', 'an unrecorded request raises ReplayMiss naming it; a replay never guesses'), ]) }} {% endcall %} {% call step(8, 'Offline: a bundle, with no MAYA at all') %}

maya.offline(bundle) opens a reproducibility bundle and serves the same read calls from it. Every file hash and the signature are checked first; a tampered bundle is refused, not partly served.

{% call example('Read and evaluate a bundle on a laptop', 'python') %} import numpy as np import maya.sdk as maya with maya.offline("calibration.zip") as off: print(off.verify()["verified"]) # hashes, signature, canonical data hash table, manifest = off.training_data() # the rows, checksum-verified params = off.parameters() out = off.predict({"x": np.array([1.0, 2.0])}) # the signed formula IR, evaluated {% endcall %} {% call warn('It never runs the code a bundle carries') %}

predict evaluates the signed formula IR with MAYA's own evaluator; the bundle's reference_model.py is not imported, because a bundle may come from outside. Calls a bundle cannot answer — the catalog, workflow, other warrants — raise NotInBundle.

{% endcall %} {% endcall %} {% call tip('Async, and in-process') %}

maya.sdk.AsyncClient has the same surface for asyncio code — it is what the web tier itself uses. Passing app= to either client runs against an in-process ASGI app, which is how MAYA's own tests exercise the full stack without a server.
