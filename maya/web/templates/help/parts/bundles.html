{% from "help/_macros.html" import step, concept, tip, warn, example, fields, screen, cards %} {% call concept('Evidence someone else can check') %}

A reproducibility bundle is a signed zip exported from a training warrant: the warrant, the model version and its formula IR, generated reference code, the parameters, the training data, the leakage certificate, the environment — and a verify.py that checks all of it without MAYA. It is what you hand to a validator or a regulator.

{% endcall %} {{ cards([ ('hash', 'Hashes every file', 'The manifest lists a SHA-256 for each file, and the list itself is Ed25519-signed.'), ('fingerprint', 'Re-hashes the data', 'The training data\'s content hash is recomputed with MAYA\'s canonical encoder, shipped inside.'), ('arrow-repeat', 'Re-executes the model', 'Where it can, the reference model is run again and its output hash compared.'), ]) }} {% call step(1, 'Export') %}

From the training warrant's page choose Export bundle, or use the SDK or CLI. The export is refused if the feature set's licence does not allow it to leave the firm.

{% call example('Export with the SDK', 'python') %} import maya.sdk as maya my = maya.connect(base_url="http://localhost:8600", api_key="maya_…") out = my.training.export_bundle(w["id"]) print(out["blob"], out["size"], out["manifest"]["reexecutable"]) {% endcall %} {% call example('Export from the command line', 'bash') %} python -m maya.cli export bundle --out pd-2026q1.zip {% endcall %} {% endcall %} {% call step(2, 'What is inside') %} {{ fields([ ('manifest.json', 'file hashes, data content hash, output hash, re-executability, signature'), ('warrant.json', 'the warrant: spec, feature set reference, contract report, backends, custody log'), ('certificate.json', 'the signed leakage certificate'), ('data/training.parquet', 'the training data, all partitions'), ('model/formula_ir.json', 'the model\'s mathematics as the typed IR'), ('model/reference_model.py', 'Python generated from the IR (only when re-executable)'), ('model/parameters.json', 'the parameter values'), ('model/spec.tex', 'the specification document source'), ('environment.json', 'Python version, declared environment and backend set'), ('model/model_version.json', 'the model version: formula, IR, hashes'), ('model/parameter_set.json', 'the parameter set the warrant was sealed with'), ('lib/canonical.py', 'MAYA\'s canonical hash — it is the definition of the hash, so it ships'), ('lib/chunker.py', 'the content-defined chunker the data hash is computed over'), ('verify.py', 'the offline verifier'), ]) }} {% endcall %} {% call step(3, 'Verify — anywhere') %}

The verifier needs Python, pyarrow and numpy; with cryptography installed it also checks the signature. It prints a JSON report and exits non-zero if anything fails.

Verify with nothing but the bundle: see Reproducibility bundles in the full reference below.

{% call example('Or with the MAYA CLI (still offline)', 'bash') %} python -m maya.cli export verify pd-2026q1.zip # [ok] file hash data/training.parquet # [ok] Ed25519 signature over the file list # [ok] data content hash (canonical, value-based) # [ok] re-execution output hash # verified: True {% endcall %}

Or upload it at {{ screen('/warrants/verify', 'Warrants → Verify a bundle') }}. Verifying runs code the bundle carries, so the server does it only for a bundle this MAYA signed whose every file still matches its signed hash, and then with MAYA's own verifier, never the uploaded verify.py. Any other bundle is reported, not executed: verify a stranger's bundle with python verify.py on your own machine.

{% endcall %} {% call warn('When re-execution is impossible, the bundle says so') %}

A declared black box has no executable specification; a composite is re-executed only when every member is closed-form (not a black box or a nested composite); and a model with parameters needs an uploaded parameter set. In those cases reexecutable is false and not_reexecutable_reason explains why; the verifier reports that check as not performed instead of implying a verification it cannot do.

{% endcall %} {% call tip('Every export is on the record') %}

Exporting writes a bundle_exported custody event on the warrant, with the bundle's digest, and an audit entry — so you can always say which bundle went to whom.
