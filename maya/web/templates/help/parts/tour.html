{% from "help/_macros.html" import step, concept, tip, warn, example, fields, screen, cards %} {% call concept('One bar, six areas, the same shape everywhere') %}

MAYA's screens hang off a single fixed bar across the top. Each area opens a panel of columns; every entry carries an icon and a one-line description, so you can find a screen by what it does. Hover to open a panel on a wide screen, or click it (and use the keyboard) anywhere. The area you are in is underlined. On a phone the bar collapses behind the button.

{% endcall %} {% call concept('The front door') %}

/ is the landing page until you sign in and your dashboard afterwards, and signing out returns you to it rather than to the sign-in form — somebody who has just left is not halfway through arriving. The landing page says what MAYA is for and draws the chain it keeps: source data, a bitemporal feature, a pin sealed by its own hash, a typed formula, a warrant without which nothing runs. Every arrow in that figure is an object MAYA stores. Help and About are reachable from it without an account.

{% endcall %}

Every list in MAYA is the same table, so these work everywhere:

{{ cards([ ('list-ol', 'Paging', '25, 50, 100, 250 or All rows per page; your choice is remembered per table.'), ('search', 'Search', 'Filters across the visible columns and highlights the matches.'), ('sort-down', 'Sort', 'Click a header to sort the whole result set; shift-click adds a second key.'), ('columns-gap', 'Columns', 'Hide and show columns from the Columns menu.'), ('file-earmark-spreadsheet', 'CSV', 'Export the current view (filter, sort, columns) as CSV.'), ('keyboard', 'Keyboard', 'Focus a table and use PageUp, PageDown, Home and End.'), ], cols=3) }} {% call concept('Big lists page from the server') %}

Features, feature sets, models, the audit explorer, the event stream and the jobs console can grow without bound, so they load one page at a time: the controls look the same, but search runs on the server over the whole list, sort applies to the columns with an arrow (one at a time), and All is not offered. CSV still exports the whole current view, fetching every page. From a script, the same lists page with a cursor:

{% endcall %} {% call example('Paging from Python', 'python') %} page = my.features.page(namespace="eq", page_size=100, sort="-updated") while page["next_cursor"]: page = my.features.page(namespace="eq", page_size=100, sort="-updated", cursor=page["next_cursor"]) for f in my.features.iter(namespace="eq"): # or let the SDK follow the cursors print(f["name"]) {% endcall %} {% endcall %} {% call step(4, 'Everything you see is an SDK call') %}

The web UI holds no privileges of its own: every screen calls the public Python SDK with your session. So anything you can click, a script can do.

{% call example('The same list the Catalog shows', 'python') %} import maya.sdk as maya my = maya.connect(base_url="http://localhost:8600", api_key="maya_…") for f in my.features.list(namespace="eq"): print(f["name"], f["latest_state"]) {% endcall %}

See The Python SDK and REST API; the live API reference is at /api/v1/docs.
