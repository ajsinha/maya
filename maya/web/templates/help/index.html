Concepts

Definition, version, pin

A definition is how a number is produced, editable while a draft. Submitting mints a version: immutable, identified by a definition hash; cosmetic edits do not mint one. A pin materializes a version: resolved, quality-checked, written as content-addressed fragments, hashed and sealed. A version freezes how; a pin freezes what. References: maya://feature/ns/name@v3 (a version), maya://feature/ns/name#eom/2026-03-31 (a pin in the eom series).

Bitemporality

Every row carries an event time (what the value is about) and a knowledge time (when MAYA could first have known it). A restatement is a new knowledge-time row, never an overwrite, so "what did we know on 31 March" stays answerable: resolve with as_of_known. Training warrants carry a signed leakage certificate proving no row used a value known after its event time.

Warrants

A training warrant binds a model version to a feature set pin; downloads are checksummed and a parameter upload must name the checksum it trained on, or it is flagged unverified_data. An execution warrant is a live licence to run: short-lived signed tokens, covenants whose breach suspends it, revocation that fails every consuming call closed. A bundle verifies offline, re-executing the model where it can and saying so where it cannot.

Workflow

One state machine: draft → in review → approved → published → deprecated → retired. Policies are data, edited in the UI, validated as they are edited and activated by a second administrator. Checks block transitions by name; segregation of duties stops you approving what you created; break-glass is loud and permanent. Your personal scratch.<you> namespace has no ceremony at all, and says so.

The table contract

Every table pages (25/50/100/250/All, remembered), searches across visible columns with highlighting, sorts the whole result set (shift-click for a second key), hides columns and exports the current view as CSV. Keyboard: focus a table and use PageUp/PageDown/Home/End.

The web UI is an SDK client

Every screen calls the public Python SDK with your own session token. Anything you can do here, a script can do with maya.sdk; see the API reference at /api/v1/docs.
