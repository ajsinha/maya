Quick reference

Run it

python run_maya_web.py
then open http://localhost:8600
First sign-in: admin / maya-dev-admin — change it after you sign in (MAYA insists only when auth.password.force_change is on).

References

maya://feature/ns/name@v3 — a version
maya://feature/ns/name#eom/2026-03-31 — a pin
maya://featureset/ns/name@v2 — a feature set version

Script it

import maya.sdk as maya
my = maya.connect(base_url="http://localhost:8600", api_key="maya_…")
Everything the UI does goes through that SDK. See the SDK topic.
