{% extends "help/_topic.html" %} {% from "help/_macros.html" import step, concept, tip, warn, example, fields, screen, cards %} {% block body %} {% call concept('Terms that follow the data') %}

A feature built on licensed market data inherits that vendor's terms, and so does everything built from it. MAYA lets a source declare its terms in a licence block, and computes an object's effective licence as the most restrictive combination of everything it is built from: its own declaration, the parent it extends, the operands it is derived from, the members of a feature set. Because the vocabulary is closed and ordered, "most restrictive" is arithmetic, not a judgement call — and every combined term remembers which source imposed it, so a refusal names the clause and the vendor instead of just saying no.

The vocabulary

{{ fields([ ('vendor', 'who the terms come from; accumulated for attribution'), ('redistribution', 'none < internal < external < public — how far the data may travel'), ('derived_works', 'forbidden < attribution < allowed — whether a derived feature or trained model may be built on it'), ('population', 'groups or desk: entries allowed to receive it; combined by intersection'), ('retention_days', 'a positive number of days; the shortest wins'), ('notes', 'free text for the reviewer; not enforced'), ]) }} {% call tip('What redistribution means in practice') %}

none: viewable and usable inside MAYA, but never leaves in bulk. internal: downloads within the firm. external: to regulators and counterparties, in a reproducibility bundle. public: anywhere. Leaving the block out is the same as public and allowed with no population limit.

{% endcall %} {% call step(1, 'Declare terms on a source') %}

In the {{ screen('/workbench/features/new', 'Workbench → Feature designer') }}, open the Licence panel and fill in the vendor and terms. In a definition, it is one more key:

{% call example('A licence block in a feature definition', 'json') %} { "index": ["date", "symbol"], "schema": [{"name": "close", "type": "float64"}], "source": {"type": "csv"}, "resolution": {"grid": "as_is", "rules": {}}, "licence": { "vendor": "Acme Data", "redistribution": "internal", "derived_works": "attribution", "population": ["desk:rates", "quant-research"], "retention_days": 365 } } {% endcall %}

An unknown term or a value outside the vocabulary is a validation error when the version is submitted, not a surprise at first export.

{% endcall %} {% call step(2, 'See the effective licence') %}

Every feature and feature set page shows an Effective licence panel with each term and who imposed it, and tells you if you are outside the permitted population. From a script:

In the SDK the same refusal raises maya.sdk.LicenceBreach, so a pipeline can catch it by name.

{% endcall %} {% call warn('Terms are declared, not discovered') %}

MAYA enforces the terms you give it; it cannot read a vendor contract. Agree the vocabulary mapping with legal once, record it in the notes, and have the licence block reviewed like any other part of the definition — it is inside the versioned definition, so a change to it is a new version.
