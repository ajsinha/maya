{% extends "help/_topic.html" %} {% from "help/_macros.html" import step, concept, tip, warn, example, fields, screen, cards %} {% block body %} {% call concept('MAYA in sixty seconds') %}

MAYA is the system of record for quantitative features, feature sets, models and the warrants that license a model to be trained or run. A number is defined once, versioned when submitted, approved by someone else, and pinned — frozen as hashed data — so that any result a model produced can be rebuilt exactly, years later, by someone who was not there. Everything is audited, and nothing approved is ever edited in place.

{% endcall %} {{ cards([ ('pencil-square', 'Define', 'Describe how a number is produced: its index, schema, source and resolution rules.'), ('check2-circle', 'Approve', 'Submitting mints an immutable version; a second person approves it.'), ('pin-angle', 'Pin', 'Freeze exactly what the data was, as content-addressed, sealed fragments.'), ]) }} {% call step(1, 'Install and run') %}

You need Python 3.13 and nothing else: SQLite, local storage and an in-process job queue are the defaults. PostgreSQL is one setting away when you need it (see Configuration and databases).

{% call example('Install', 'bash') %} git clone https://github.com/ajsinha/maya.git cd maya python -m venv .venv && source .venv/bin/activate pip install -r requirements.txt {% endcall %} {% call example('Start the server', 'bash') %} python run_maya_web.py # MAYA listens on http://localhost:8600 (override: --server.port=9000) {% endcall %} {% call tip('Any setting, from the command line') %}

Every key in config/application.yaml can be overridden as --key=value, for example --db.dialect=postgresql. run_maya_web.py is the only supported way to start MAYA.

{% endcall %} {% endcall %} {% call step(2, 'Sign in and change the bootstrap password') %}

Open http://localhost:8600 and sign in as admin with maya-dev-admin. MAYA makes you choose your own password before anything else, and shows a warning on every page until you do.

{% call warn('The bootstrap password is public') %}

It is printed in this help and in the README. Outside a laptop, change it before creating any data, then create named accounts: Admin → Users & roles.

{% endcall %} {% endcall %} {% call step(3, 'Your first feature, from one CSV') %}

The fastest route is {{ screen('/workbench/quick', 'Workbench → Quick feature') }}. Give it a CSV with a date column and it infers the schema, creates the feature in your personal scratch.<you> namespace, ingests the rows and submits version 1.

{% call example('prices.csv', 'csv') %} date,symbol,close 2026-01-02,AAA,101.5 2026-01-02,BBB,52.0 2026-01-05,AAA,102.1 2026-01-05,BBB,51.4 {% endcall %}

The same thing from the command line, or from Python:

{% call example('Command line', 'bash') %} python -m maya.cli feature quick prices.csv --name prices {% endcall %} {% call example('Python SDK', 'python') %} import maya.sdk as maya my = maya.connect(base_url="http://localhost:8600", api_key="maya_…") out = my.features.quick(open("prices.csv", "rb").read(), name="prices") print(out["ref"], out["rows"]) # maya://feature/scratch.admin/prices 4 {% endcall %} {% call tip('Scratch has no ceremony, and says so') %}

Your scratch namespace skips review so you can explore freely. Anything that matters belongs in a governed namespace, built with the full feature designer.

{% endcall %} {% endcall %} {% call step(4, 'Look at it') %}

Open the feature from {{ screen('/catalog/features', 'Catalog → Features') }}. Every object page has the same five tabs:

{{ fields([ ('Overview', 'versions with their state, the ingests (knowledge-time batches), the effective licence'), ('Definition', 'the exact definition behind each version, as JSON'), ('Data', 'a live, resolved preview of any approved version or sealed pin'), ('Lineage', 'what this is built from and what is built on it'), ('History', 'every transition, who made it, and the comments'), ]) }} {% endcall %} {% call step(5, 'Approve and pin it') %}

In a governed namespace a different person approves the submitted version — separation of duties stops you approving your own work. Once approved, pin it: MAYA resolves the data as of a date, runs the quality contract, writes content-addressed fragments and seals them.

{% call example('Pin month-end', 'bash') %} python -m maya.cli feature pin eq/prices --version 1 --name eom --as-of 2026-01-31 # → maya://feature/eq/prices#eom/2026-01-31 {% endcall %}

That reference now means the same bytes forever. Train against it, cite it in a report, hand it to a validator: they will all see exactly what you saw.
