Every model has to answer one question. MAYA keeps the answer.

A model said a number. Which data did it see, as the data stood then? Which version of the mathematics, which parameters, whose approval? MAYA is the record that answers that months later, without anybody having to remember — features that keep two clocks, a formula the platform can evaluate itself, and a warrant that has to exist before a model may be fitted or run.

Features that remember when they were true

A value carries the moment it describes and the moment MAYA learnt it. Ask a feature what it held on a date, and you get what was known then — not what a later correction says now.

Mathematics the platform can read

A model is registered as a typed expression, parsed from LaTeX or Python. MAYA generates its own reference implementation from that tree and checks your code against it.

Training and execution under warrant

Fitting a model draws on sealed pins under a training warrant; scoring runs under an execution warrant with covenants on its inputs and outputs. Both are records, not conventions.

Evidence somebody else can check

Leakage certificates, conformance runs and signed evidence bundles: the point is never MAYA's word for it, but a file a reviewer can open and verify without MAYA installed.
