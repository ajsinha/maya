The chain

One value, making the whole journey.

A value leaves its source, is read as of a moment, is sealed by the hash of its own contents, meets the mathematics, and only then is allowed to run. Every box in this figure is an object MAYA stores, with a version, an owner and an audit trail — so the picture is not a metaphor for the system. It is the system.

Two clocks

A value is evidence only as of when it was known.

Every value MAYA holds carries two times: when it was true, and when MAYA learned it. A training set built as of a date admits only what could have been known by then, and the leakage certificate refuses a row whose knowledge time runs past its event time plus the declared lag.

Capabilities

Not a model inventory. A model record.

An inventory lists what exists. A record can say what a model saw, what it computed and who allowed it — and refuse the run when one of those is missing.

Features that remember when they were true

Every value carries the moment it describes and the moment MAYA learnt it. A restatement is a new record, never an overwrite, so a training row rebuilt a year later is the row built then.

Pins sealed by their own contents

A pin is named by the hash of what it holds. The same data pinned twice is the same pin, and changed data cannot hide behind an unchanged name.

Mathematics the platform can read

Write a model in LaTeX; MAYA parses it into a typed tree, renders it back so a misreading shows, and generates its own reference implementation to check your code against.

Training and execution under warrant

Fitting draws on sealed pins under a training warrant with a leakage certificate. Scoring runs under an execution warrant whose covenants can suspend it in production.

Composites governed as one model

Ensembles, pipelines, routers: one contract computed from the members, one approval for the whole, and maturity capped at the least mature part.

Evidence somebody else can check

A bundle carries the pins, the parameters, the certificates and a verifier that runs on a machine with no MAYA installed. The point is never MAYA's word for it.

Four ways in

Four ways in. One API.

The web application is an SDK client with no private path, so whatever a person can do on screen, a script can do the same way — and be refused the same way.

from maya.sdk import connect

my = connect(api_key="maya_…")
w  = my.training.create("retail", "pd_fit",
        model="retail/pd_scorecard@v1",
        featureset="retail/panel#q2/2026-06-30")
rows = w.data()        # sealed pin, leakage-certified
w.upload_parameters(fit(rows), data_checksum=rows.checksum)
w.submit()               # and a second person approves

The record

Months later, the record still answers.

Every change is an entry in an audit log chained by hash, so history cannot be quietly rewritten, and the chain head can be anchored outside the database. The same log records what MAYA refused, and why.
