{% endif %} {% call needs('feature-sets', 'What a feature set needs') %}
  • Members: each maps an attribute name in the set to a feature reference and that feature's attribute; optionally a cast and a fill rule.
  • Index: the set's keys, e.g. date, symbol. Every member must carry them or be aligned to them.
  • Grid: as_is keeps the data's own rows; a calendar (NYSE, ISO_business_days…) puts every key on it.
  • Alignment: inner (keys every member has), outer (any member), left (one driving member), or asof (others matched to the driver's dates within a tolerance, usually looking backward).
  • Pinning needs every member pinned; cascade pins them together and rolls all back if one fails.
