{% call needs('training-warrants', 'What a training warrant needs') %}
  • An approved model version and a feature set, best a sealed pin (maya://featureset/ns/panel#q1/2026-03-31), which never moves.
  • The target attribute. Bindings only where a model input's name differs from the attribute, e.g. {"income": "gross_income"}.
  • Split fractions that add up to 1 (default 0.7 / 0.15 / 0.15). Rows at random hashes each row with the seed; by date holds out the last dates, which a time series needs.
  • Holdout escrowed keeps the test rows sealed; every scoring attempt on them is counted.
  • Leakage lag: how many days after its event date a value may be known. Later rows go on the leakage certificate, which must be clean or justified in writing.
{% endcall %}

MAYA validates the model's input contract against the feature set before issuing, listing every mismatch, and signs a leakage certificate over every row.
